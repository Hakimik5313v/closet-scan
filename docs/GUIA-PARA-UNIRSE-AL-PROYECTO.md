# 🚀 Guía Completa: Unirse al Proyecto Closet/Scan en GitHub

> **Para quién es esta guía:** Tú o cualquier compañero del equipo que quiera contribuir al proyecto.  
> **Tiempo estimado:** 15 a 20 minutos.  
> **Requisitos:** Tener internet y una cuenta en GitHub (se crea gratis en github.com).

---

## PASO 1: Crear tu cuenta de GitHub (si no tienes)

1. Ve a [https://github.com](https://github.com)
2. Haz clic en **Sign up** (Registrarse).
3. Pon tu correo, una contraseña y un nombre de usuario (el nombre de usuario es público, elige algo profesional como `tunombre-dev`).
4. Verifica tu correo.
5. **Dile a Ricardo tu nombre de usuario de GitHub** para que te agregue como colaborador.

---

## PASO 2: Aceptar la invitación al repositorio

1. Cuando Ricardo te agregue, recibirás un correo de GitHub con asunto:  
   *"You've been invited to collaborate on lopezperezricardo0316-a11y/closet-scan"*
2. Haz clic en el botón verde **Accept invitation** (Aceptar invitación).
3. Si no ves el correo, revisa la carpeta de **Spam / Correo no deseado**.
4. También puedes ir directamente a:  
   👉 [https://github.com/lopezperezricardo0316-a11y/closet-scan/invitations](https://github.com/lopezperezricardo0316-a11y/closet-scan/invitations)

---

## PASO 3: Instalar GitHub Desktop

GitHub Desktop es una aplicación visual para trabajar con el código sin necesidad de escribir comandos en la terminal.

1. Ve a [https://desktop.github.com](https://desktop.github.com)
2. Descarga la versión para tu sistema operativo (Windows, Mac o Linux).
3. Instala la aplicación normalmente.
4. Al abrirla, haz clic en **Sign in to GitHub.com**.
5. Se abrirá tu navegador → haz clic en **Authorize desktop** (Autorizar).
6. Listo, ya estás conectado con tu cuenta.

---

## PASO 4: Clonar (Descargar) el repositorio del proyecto

"Clonar" significa descargar todo el código y los archivos del proyecto a tu computadora.

1. En GitHub Desktop, ve a **File → Clone repository...** (Clonar repositorio).
2. En la pestaña **GitHub.com** busca el repositorio: `closet-scan`  
   (debes verlo porque ya tienes acceso).
3. En **Local path** (Ruta local), elige la carpeta donde quieres guardar el proyecto.  
   📌 **Recomendado:** Guárdalo en `Documentos/closet-scan`
4. Haz clic en **Clone** (Clonar).
5. GitHub Desktop descargará todos los archivos automáticamente. ¡Ya tienes el proyecto en tu computadora!

---

## PASO 5: Abrir los archivos del proyecto

Una vez clonado, puedes ver los archivos del proyecto de dos formas:

### A. Desde GitHub Desktop
- Haz clic en **Repository → Show in Explorer** (Windows) o **Show in Finder** (Mac).
- Se abrirá la carpeta con todos los archivos.

### B. Desde VS Code (Recomendado para editar código)
- Si tienes VS Code instalado, en GitHub Desktop haz clic en **Repository → Open in Visual Studio Code**.
- Si no tienes VS Code, descárgalo gratis en [https://code.visualstudio.com](https://code.visualstudio.com).

---

## PASO 6: El flujo de trabajo diario (Cómo colaborar sin romper nada)

Cada vez que quieras trabajar en el proyecto, sigue este orden:

### 1️⃣ Antes de empezar: Actualizar (Fetch + Pull)
En GitHub Desktop, haz clic en **Fetch origin** (el botón en la barra superior).  
Si aparece un botón que dice **Pull origin**, haz clic en él también.  
*(Esto descarga los cambios que hayan hecho tus compañeros)*

### 2️⃣ Trabaja en tu tarea
Edita los archivos que corresponden a tu parte del proyecto.

### 3️⃣ Guardar tus cambios: Commit
Cuando termines algo concreto:
1. En GitHub Desktop, en el panel izquierdo verás todos los archivos que cambiaste (en verde = nuevos, en amarillo = modificados, en rojo = borrados).
2. Abajo a la izquierda, en el campo **Summary**, escribe un mensaje corto que describa qué hiciste.  
   Ejemplos:
   - `feat: pantalla de login y registro de usuario`
   - `fix: corregir error al guardar prenda`
   - `docs: actualizar documentacion del armario`
3. Haz clic en el botón azul **Commit to main**.

### 4️⃣ Subir tus cambios: Push
Haz clic en el botón azul **Push origin** (arriba a la derecha).  
*(Esto sube tus cambios a GitHub para que el equipo los vea)*

## 🆘 Reglas básicas del equipo para no romper nada

| Regla | ¿Por qué? |
|:------|:----------|
| Siempre haz **Fetch + Pull** antes de empezar a trabajar | Para no quedarte desactualizado y generar conflictos |
| Haz commits pequeños y frecuentes | Más fácil revertir si algo sale mal |
| Escribe mensajes de commit descriptivos | Tus compañeros saben qué hiciste sin tener que leer el código |
| Nunca borres archivos de otro sin avisarle | Coordinación básica de equipo |
| Si hay un **conflicto** (GitHub Desktop te avisa), avísale a Ricardo | Él tiene más experiencia resolviéndolos |
